Modules

Everything Ticket provides today: the Ticket.* modules and the zones its plugin adds to Polar.

Modules

ModuleWhat
Ticket.HtmlHtml, the Render and Attr traits, escape, raw, document, scripts
Ticket.Responserender, render_status, redirect_to, head, with_header, content_type, text, html, view, json, empty, redirect, not_found
Ticket.ActionFilter, before
Ticket.ErrorHalt
Ticket.ConnConn, from_request, with_path_params, header, rescue_halt (used by the router)
Ticket.Paramsstring, int, id, nested
Ticket.QueryStringparse: a query string or urlencoded body to a last-wins Map
Ticket.Cookiesparse: a cookie header to a Map
Ticket.DbThe Db effect (connect, query, exec, script), SqlValue, DbConfig, DbError, DbFailure, Changes, all, one, transaction
Ticket.MigrationColumn, Index, Change, Migration (what the migrations zone generates), up_sql, down_sql, sql
Ticket.Migraterun: the db:* commands over Schema.migrations
Ticket.QueryColumn, Filter, Clause, the ToSql trait, eq, not_eq, lt, gt, like, is_null, order_asc, order_desc, limit, offset
Ticket.SqlStatement, and the SQL for find, select, count, insert, update, delete
Ticket.ModelWhat the generated Posts binds call: find, all, filter, count, insert, update, delete

Zones

ZoneGeneratesGuide
routesrouter, route_table, path helpers, and the sibling module PathsRouting
viewsOne function returning Html per viewViews
migrationsRecords, insert types, column constants, the per-table effect and its binds, and the migrations listDatabase
view_componentname(props: {…}) functions usable as <Module.Name />Components

The zones are Rust plugins that Polar builds the first time you build an app that depends on Ticket. The code they generate is type-checked like your own.
